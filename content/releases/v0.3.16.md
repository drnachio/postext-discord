The first version of Postext published on npm: a layout engine that turns semantic markdown into publication-grade pages.

### ✨ Layout engine
• Markdown parsing with frontmatter, inline formatting, lists and LaTeX math
• Fast text measurement with caching, and a layout worker that builds documents off the main thread
• Knuth-Plass justification with configurable penalties for orphans, widows and runts
• Keep-with-next and keep-colon-with-list rules for headings and lists
• Multi-column layouts with column rules, cut lines and paragraph spacing
• Headings with numbering templates and indent-after-heading control
• Pagination: numbering formats, forced page breaks, odd/even parity and PDF page labels
• Headers and footers, with editable content per page
• Resources: `::resource` blocks and `:ref` cross-references, typed numbering, tables (with merged cells) and SVG figures with captions

### 🖨️ Rendering
• HTML and canvas backends, including rendering pages to bitmaps
• PDF output with embedded custom fonts, colours, LaTeX math and resource blocks

### 🧪 Sandbox
• Interactive editor with undo/redo, warnings panel and a live preview
• Configuration panels for page, layout, body text, headings, lists, resources, captions and tables
• Custom font management (families, variants, preloading) and colour pickers with alpha
• Resources panel with drag-and-drop uploads, a table editor and caption editing

### 🌐 Website & project
• Landing page, documentation with search, and Spanish localization
• Contributing guide, issue and pull request templates, and automated releases to npm
