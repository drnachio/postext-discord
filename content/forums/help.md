Ask anything about using Postext. One question per post, please.

✅ A good post includes: Postext version, environment (browser / Node.js / worker), a minimal markdown + config snippet in a code block, and expected vs. actual result. Screenshots help with layout issues.

🏷️ Pick at least one tag. When your question is answered, add the ✅ Solved tag.
🐛 Confirmed bugs are moved to GitHub Issues. 🔒 Security problems: never post them here, see SECURITY.md.

**Welcome to {#help}!** Before posting:

**1. Search first.** Your question may already be answered here or in the [docs](<{link:docs}>).
**2. Reproduce it in the [sandbox](<{link:sandbox}>)** if you can. It's the fastest way to share a reproducible case.
**3. Use this template:**
```
**What I'm trying to do:**
**Postext version / environment:**
**Minimal input (markdown + config):**
**What I expected:**
**What happened (+ screenshot):**
```
**4. Tag your post** (Question, Possible bug, PDF output, etc.) and give it a descriptive title. For example, *"Figure floats to next page even when there's room"* works much better than *"help pls"*.
**5. Mark it ✅ Solved** once it's answered, so others can find the solution.

Please don't ping maintainers or other members for help. Everyone here volunteers their time 💙
